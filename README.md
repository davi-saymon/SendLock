# SendLock 🔒

> Plataforma web para compartilhamento rápido e seguro de arquivos temporários sem necessidade de login.

---

## 📌 Sobre o Projeto

O **SendLock** é um projeto prático desenvolvido para a disciplina de **Projetos Profissionalizantes** do curso de **Análise e Desenvolvimento de Sistemas (ADS)** na Faculdade Grau Técnico.


A proposta da ferramenta é resolver o dilema entre praticidade e segurança no envio de arquivos temporários:
- Unir a **agilidade e falta de burocracia** de plataformas como o *Filebin* (sem necessidade de cadastro ou e-mail);
- Com o **controle de permissões e segurança** de ferramentas como o *Google Drive* (impedindo que convidados apaguem arquivos alheios sem autorização).

---

## 🚀 Funcionalidades do MVP (Produto Mínimo Viável)

- **Criação de Salas Temporárias:** Acesso imediato por um link único sem criação de conta.
- **Hierarquia de Permições:**
  - *Administrador (Criador):* Controle total da sala, gerenciamento e exclusão de arquivos.
  - *Coanfitriões:* Permissão para gerenciar e excluir arquivos concedida pelo Admin.
  - *Membros/Convidados:* Permissão para visualizar, baixar e enviar (upload) seus próprios arquivos.
- **Upload e Download simplificados:** Interface direta para envio e recebimentos dos arquivos.
